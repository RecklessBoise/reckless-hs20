Première version du **Reckless HS20**, un synthé semi-modulaire inspiré du MS-20.

- VST3, AU et application Standalone pour macOS (binaire universel Apple Silicon + Intel)
- Architecture MS-20 complète : 2 VCO, HPF + LPF « 35 » auto-oscillants (modèles Rev 1 / Rev 2), EG1 / EG2, MG, S&H, ESP
- Patch panel avec 6 câbles virtuels à brancher à la souris
- Mono fidèle + mode Poly 8 voix
- 196 presets d'usine, système de ❤️ likes et banque Liked exportable
- Interface en métal usé, redimensionnable de 50 % à 200 %

Installation : dézippe, puis copie le `.vst3` dans `~/Library/Audio/Plug-Ins/VST3/` et le `.component` dans `~/Library/Audio/Plug-Ins/Components/`.
Les binaires ne sont pas notarisés : voir le README pour la commande `xattr`.
